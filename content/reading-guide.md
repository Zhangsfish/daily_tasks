这是一份**有出处的阅读入口**。每条消息保留原文标题、发布时间、原文链接与另一家独立媒体的报道。你可以先扫标题，再点开原文核对细节。

## 看清每条新闻的边界

| 标记 | 含义 |
| --- | --- |
| 原文时间 | 第一来源发布这篇报道的时间，统一显示为北京时间。 |
| 交叉来源 | 另一家独立媒体对相似事件的报道及其发布时间。 |
| 核查边界 | 自动流程能确认什么、仍有哪些不确定性。 |

> 两家来源标题相近，只能为报道主题提供交叉证据。正文中的数字、引述与后续变化仍值得查阅原文。

新闻采集和入选的完整规则在[公开 skill](skills/news-collection/SKILL.md)中。若一栏没有条目通过核查，系统会停止生成当期简报，继续保留上一期及其日期。

## 用 Markdown 写内容

后续专题文章可以存放在 `content/` 目录，以普通 Markdown 编写标题、列表、引用、表格、代码和链接，并在 `content/index.json` 登记。文章正文中的原始 HTML 不执行。

需要图表时，添加语言名为 `chart` 的代码围栏，内容使用 JSON。支持 `bar`（柱状图）和 `line`（折线图）；普通图表必须给出标签、非负数值、数据来源与来源链接。例如下面是**格式示例，不是新闻数据**：

~~~json
{
  "type": "line",
  "title": "格式示例",
  "labels": ["甲", "乙"],
  "values": [0, 0],
  "unit": "单位",
  "source": "示例数据",
  "source_url": "https://example.com/data"
}
~~~

本站不把图表装饰成事实：来源或数据格式缺失时，图表会显示错误说明。
